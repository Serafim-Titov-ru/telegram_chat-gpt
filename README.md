# 🤖 Telegram ChatGPT Bot

Телеграм-бот на основе OpenAI GPT-4o с поддержкой текста, голосовых сообщений, фото, документов и генерации изображений.

---

## Возможности

- **Текстовый чат** — диалог с GPT-4o с сохранением контекста
- **Голосовые и кружочки** — расшифровка через Whisper и ответ от GPT
- **Фотографии** — анализ изображений через Vision
- **Документы** — чтение и анализ .txt, .pdf, .docx, .py, .json и других форматов
- **Аудио/видео файлы** — транскрипция речи
- **Генерация изображений** — по обычной фразе, например: `сгенерируй фото закат над морем`
- **Редактирование фото** — отправь фото с подписью типа `убери фон` или `добавь снег`
- **Промокоды** — активация через `/promo КОД`
- **Реферальная система** — пригласи друга через свою ссылку
- **Панель администратора** — рассылка, баны, лимиты, промокоды

## Установка

### 1. Клонируй репозиторий

```bash
git clone https://github.com/youruser/yourrepo.git
cd yourrepo
```

### 2. Установи зависимости

```bash
pip install python-telegram-bot openai aiosqlite
```

Опционально, для чтения PDF и DOCX:

```bash
pip install PyPDF2 python-docx
```

### 3. Настрой конфигурацию

Открой `bot.py` и заполни константы в начале файла:

```python
TELEGRAM_BOT_TOKEN = "ВАШ_ТОКЕН_БОТА"   # токен от @BotFather
OPENAI_API_KEY     = "ВАШ_КЛЮЧ_OPENAI"  # ключ с platform.openai.com
ADMIN_IDS          = [123456789]          # твой Telegram ID
```

Как получить токен бота: напиши [@BotFather](https://t.me/BotFather) → `/newbot`.

Как узнать свой Telegram ID: напиши [@userinfobot](https://t.me/userinfobot).

### 4. Запусти бота

```bash
python bot.py
```

## Как работает

### Обработка сообщений

Когда пользователь пишет боту, `handle_text` проверяет:

1. Не забанен ли пользователь
2. Не превышен ли дневной лимит сообщений
3. Содержит ли текст запрос на генерацию изображения (ключевые слова: `сгенерируй`, `нарисуй`, `создай` + `фото`/`картинку`)
4. Если нет — отправляет запрос к GPT и возвращает ответ

### Контекст диалога

История сообщений хранится в SQLite и передаётся в GPT при каждом запросе. Последние `MAX_CONTEXT_MSGS = 20` сообщений. Очистить историю — команда `/new`.

### Генерация изображений

Работает через OpenAI Images API. Используются модели в порядке приоритета: `gpt-image-1.5` → `gpt-image-1` → `dall-e-3`. Если одна не доступна — автоматически пробует следующую.

### База данных

SQLite-файл `bot_database.db` создаётся автоматически при первом запуске. Содержит таблицы:

| Таблица | Назначение |
|---|---|
| `users` | Пользователи, их модель GPT и системный промпт |
| `usage` | Статистика использования по дням |
| `conversations` | История сообщений для контекста |
| `promo_codes` | Промокоды |
| `referrals` | Реферальные связи |
| `app_config` | Настраиваемые лимиты |

## Настройки и лимиты

Лимиты задаются в начале `bot.py` и могут быть изменены через панель администратора в боте:

```python
FREE_DAILY_LIMIT        = 30  # сообщений в день
FREE_IMAGE_DAILY_LIMIT  = 5   # генераций изображений в день
FREE_MEDIA_DAILY_LIMIT  = 5   # загрузок фото/документов в день
MAX_CONTEXT_MSGS        = 20  # глубина истории диалога
MAX_FILE_SIZE_MB        = 20  # макс. размер файла
```

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и меню |
| `/new` | Очистить историю диалога |
| `/stats` | Статистика пользователя |
| `/settings` | Выбор модели GPT и системный промпт |
| `/promo КОД` | Активировать промокод |
| `/ref` | Реферальная ссылка |
| `/help` | Справка |

## Панель администратора

Доступна пользователям из списка `ADMIN_IDS`. Открывается кнопкой **Панель Admin** в меню.

Возможности:
- **Статистика** — кол-во пользователей и сообщений за день
- **Рассылка** — отправить сообщение всем пользователям
- **Промокод** — создать промокод на N дней
- **Лимиты** — изменить дневные лимиты без перезапуска бота
- **Бан / Разбан** — заблокировать пользователя по ID
